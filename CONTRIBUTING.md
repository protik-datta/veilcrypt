# Contributing to Veilcrypt

Thank you for your interest in contributing to Veilcrypt.

Veilcrypt is an open-source, privacy-focused file encryption project. Contributions that improve security, reliability, performance, usability, documentation, and developer experience are welcome.

## Ways to Contribute

You can contribute by:

- Reporting bugs
- Reporting security vulnerabilities
- Improving documentation
- Fixing bugs
- Adding tests
- Improving the C cryptographic engine
- Improving the Node.js backend
- Improving the React frontend
- Improving performance
- Improving accessibility and UX
- Suggesting new features
- Reviewing pull requests

## Before You Start

Please read:

- `README.md` for project architecture and setup
- `SECURITY.md` for security-related issues
- `LICENSE` for licensing information

Security vulnerabilities should **not** be reported through public GitHub Issues.

## Development Setup

### Requirements

Depending on the part of the project you are working on, you may need:

- Git
- Node.js
- npm
- C compiler
- Make
- OpenSSL development libraries
- A modern web browser
