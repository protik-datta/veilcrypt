# Code of Conduct

## Our Pledge

We are committed to making participation in Veilcrypt a respectful, inclusive, and welcoming experience for everyone.

We welcome contributions from people of all backgrounds and levels of experience.

## Expected Behavior

Examples of behavior that contribute to a positive environment include:

- Being respectful and considerate toward other contributors.
- Welcoming different perspectives and approaches.
- Providing constructive and actionable feedback.
- Focusing on technical issues rather than individuals.
- Accepting constructive criticism gracefully.
- Taking responsibility for mistakes and learning from them.
- Respecting the project's security and privacy principles.

## Unacceptable Behavior

The following behavior is not acceptable:

- Harassment, discrimination, or personal attacks.
- Trolling, insulting, or deliberately inflammatory comments.
- Publishing someone's private information without permission.
- Threats or intimidation.
- Sexualized language or unwanted sexual attention.
- Deliberate disruption of project discussions or contributions.
- Malicious activity against project infrastructure or contributors.
- Sharing security vulnerabilities publicly before they have been responsibly reported.
- Any other conduct that would reasonably be considered inappropriate in a professional open-source community.

## Security-Related Conduct

Veilcrypt is a security-focused open-source project.

Security researchers and contributors are expected to test responsibly.

Please do not:

- Access data that does not belong to you.
- Attempt to compromise project infrastructure.
- Delete or modify other users' data.
- Perform denial-of-service attacks against project services.
- Publicly disclose an undisclosed vulnerability before giving maintainers a reasonable opportunity to respond.

Security vulnerabilities should be reported according to the process described in `SECURITY.md`.

## Enforcement

Project maintainers are responsible for clarifying and enforcing the standards of acceptable behavior.

Maintainers may take any action they consider appropriate in response to unacceptable behavior, including:

- Removing inappropriate comments or contributions.
- Closing issues or pull requests.
- Temporarily or permanently restricting participation.
- Removing access to project resources.

## Reporting

If you experience or witness unacceptable behavior, please report it privately to the project maintainers.

For security vulnerabilities, do **not** use public GitHub Issues. Follow the reporting process described in `SECURITY.md`.

## Scope

This Code of Conduct applies to all project spaces, including:

- GitHub Issues
- Pull Requests
- Discussions
- Code reviews
- Project-related communication
- Other spaces where an individual is officially representing Veilcrypt
